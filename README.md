# baby-data-analysis-portfplio
基于阿里天池淘宝母婴购物数据，对某母婴电商平台 2012 年 7 月至 2015 年 2 月的 29,971 条交易记录做了一次端到端的探索性分析。整个分析遵循“先判断数据能支撑什么，再决定做什么”的顺序：第一步做数据质量体检，发现该样本是按行随机抽样而非用户行为序列，据此主动放弃了 RFM、复购周期等依赖单用户多记录的常见框架；随后围绕时间节奏、品类结构、购买量分布、异常订单与宝宝画像五个方向展开分析，产出 16 张图表与 24 份指标明细表；最后针对数据支撑充分的囤货订单识别任务训练分类模型，5 折交叉验证 ROC-AUC 达 0.778。全部结果可通过 python scripts/run_all.py 一条命令复现。
