# 数据说明

## 数据来源

本项目的原始数据来自 **阿里云天池 · 淘宝母婴购物数据集（Baby Goods Info Data）**。

- 数据集主页：https://tianchi.aliyun.com/dataset/45
- 数据提供方：淘宝 / 天猫
- 数据性质：已脱敏、已抽样（用户 ID、商品 ID、类目 ID、属性键均已做匿名化处理）
- 使用目的：数据分析学习与作品展示，不作商业用途

> 本项目使用的是该数据集公开的**采样样本**，并非全量数据。
> 全量数据约含 9,000,000+ 条儿童信息与 2,990,000+ 条交易记录，需在天池平台登录后获取。

## 数据的重要结构特征

拿到数据后做的第一件事是**质量体检**，结论直接决定了后续能做什么分析：

1. **按行随机抽样，不是用户行为序列**
   29,971 笔交易对应 29,944 个用户，人均仅 **1.0009 笔**，只有 25 个用户存在复购。
   → 无法构造用户级行为特征，因此 **RFM、复购周期、用户生命周期、性别预测等分析在本数据上不成立**。

2. **存在极端大额订单**
   单笔最大购买 **10,000 件**（童装 / 童鞋），一笔即占全部件数的 **13.1%**；Top10 大单合计占 **27.5%**。
   → 所有「平均值」类指标都需给出「含 / 不含大单」两个口径。

3. **时间区间不完整**
   数据覆盖 2012-07-02 ~ 2015-02-05，其中 **仅 2013、2014 两个年度是完整的**。
   → 趋势与季节性分析只使用这两个年度。

4. **无金额字段**
   只有数量（`buy_mount`）没有成交金额，所有规模结论均为**件数口径**，不等同于 GMV 口径。
