## 一、30 秒版本（自我介绍时用）

> 我做了一个母婴电商的购物行为分析项目，用的是阿里天池公开的淘宝母婴交易数据，大概 3 万条交易记录。
> 整个流程是：先做数据质量体检，再做业务分析、可视化，最后做了一个机器学习模型，用来预测哪些订单会囤货。
> 里面最有意思的发现是，我原本以为数据能做用户复购分析，但一检查发现人均只有 1 笔交易，
> 所以主动砍掉了一部分分析方向，把精力放在数据真正能支撑的地方。

**为什么这样说有效**：主动讲「我砍掉了什么」，比罗列「我做了什么」更能体现判断力。

## 二、常见追问与回答

### Q1：这个项目你做了多久？用了什么工具？

Python + pandas 做数据处理，SciPy 做统计检验，scikit-learn 做建模，Matplotlib 画图。
代码按模块拆分（加载 / 清洗 / 分析 / 绘图 / 建模 / 报告），一条命令能跑完全流程。

### Q2：为什么不做用户复购分析？

**这是最重要的一个回答，一定要准备好。**

数据检查发现：29,971 笔交易对应 29,944 个用户，人均 1.0009 笔，只有 25 个用户有复购记录。

说明拿到的是一份**按行随机抽样的样本**，不是完整的用户行为序列。
复购分析、RFM 分层、用户生命周期，这些都需要「同一个人的多条记录」才能算，样本不支持。

所以我主动放弃了这些方向，而不是硬做出一堆看着完整、其实没有意义的结果。

### Q3：那你知道这个数据集有个经典赛题是预测宝宝性别吗？为什么不做？

知道，我实际试过。

性别预测需要**单个用户的多条购买记录**来构造行为特征。这份样本里带性别标签的用户只有 929 个，
人均可用交易记录 1.0 条，特征维度直接塌缩。

我跑了实测：5 折交叉验证下 **ROC-AUC = 0.4931**，跟随机猜（0.5）没有区别。

所以我换了一个数据能支撑的任务 —— 预测订单会不会囤货（购买 ≥ 3 件），样本量 3 万，正类占比 6.13%。

**这样回答的加分点**：你不是「不会做」，而是「验证过不可行之后主动换方向」。

### Q4：囤货预测的结果怎么样？

5 折交叉验证：

- **ROC-AUC = 0.778**
- **PR-AUC = 0.210**，而随机基线只有 0.061，提升约 3.4 倍

因为正类只占 6.13%，是不平衡分类，所以我更看 PR-AUC 而不是准确率
（模型全猜「不囤货」的准确率也有 88.8%，但那样毫无意义）。

### Q5：模型为什么用逻辑回归，不用更复杂的模型？

我同时训了逻辑回归和随机森林做对比：

- 逻辑回归 PR-AUC = 0.210
- 随机森林 PR-AUC = 0.208

差距在噪声范围内。在 44 维特征、3 万样本、正类 6% 的场景下，
我选逻辑回归，因为它更快、更容易解释、更不容易过拟合。
**追求那 0.002 的指标提升，不如换来一个更稳、更好维护的模型。**

### Q6：特征里最重要的是什么？

**商品属性维度数**，重要性 0.304，远超其他特征。

业务解释是：商品描述的属性越多，通常意味着规格越复杂、越可能是大包装或组合装，
而大包装正好是囤货行为的对象。这条逻辑是能讲通的。

时间特征（年内天数、月份周期）加起来只有 0.19 左右，
说明囤货主要由「买什么」决定，而不是「什么时候买」。

### Q7：怎么保证模型没有数据泄漏？

目标变量是「购买数量 ≥ 3 件」，所以特征里**严格排除了 `buy_mount` 以及所有由它派生的字段**
（比如 `log_buy_mount`、`is_bulk`）。

特征只用三类信息：时间特征、商品属性维度数、类目 one-hot。

### Q8：你觉得这个分析里最有价值的发现是什么？

**两个：**

**第一，异常订单的影响。** 单笔最大的一笔订单买了 10,000 件，一笔就占全部件数的 13.1%，
Top10 大单合计占 27.5%。这意味着项目里所有「平均值」指标都会被这几个订单绑架。

比如平均单笔件数看起来是 2.54 件，但剔除 Top10 大单后就只有 1.85 件。
所以在报告里我所有的规模指标都给了「含/不含大单」两个口径。

**第二，618 在当年并不成立。** 我算了各促销节点的拉动倍数：双11 是 5.19 倍、双12 是 2.26 倍，
而 **618 只有 0.64 倍，比平日还低**。

因为 2012–2014 年 618 是竞对平台的主场，在淘系母婴品类里还没形成大促心智。
这件事提醒我：**行业常识必须用数据验证，不能直接照搬。**

### Q9：为什么说性别和品类偏好没关系？

做了卡方独立性检验：**p = 0.79**，远大于 0.05，不能拒绝独立性假设；
Cramér's V = 0.051，效应量接近 0。

也就是说，在这份数据里男宝家庭和女宝家庭的品类结构几乎一样。
所以我没有把性别作为推荐维度，而是建议按月龄分层 ——
月龄的影响是显著的，比如 7–12 月龄的玩具偏好指数达到 2.85。

**这是一个「没有差异」的结论，但它直接否定了一个运营假设，同样有价值。**

## 三、如果被问到「有什么不足」

主动说，不要等面试官挑：

1. **样本是抽样的子集**，人均 1 笔交易，所以用户级分析做不了。如果拿到全量数据，
   我会重新做用户特征工程，把性别预测和复购预测再做一遍。
2. **没有金额字段**，只有购买数量。所以所有「规模」结论都是件数口径，不等于 GMV。
3. **类目名和属性键被平台脱敏了**，所以品类中文名是参考社区对照整理的，
   属性分析只能停在「描述丰富度」这一层。
4. **只有 2013、2014 是完整年度**，趋势和季节性分析限定在这个区间。

然后接一句：**「这些在项目的 README 里我都写清楚了。」**

## 六、几个可能会被问倒的问题（提前准备）

**Q：HHI 是什么？**
赫芬达尔指数，用来衡量市场集中度。算法是各个主体份额的平方和，再乘 10000。
值越大越集中。我算出来是 394.8，属于中等偏低，说明头部没有垄断品类，长尾很厚。

**Q：Cramér's V 是什么？**
卡方检验只能告诉你「有没有关系」，不能告诉你「关系有多强」。
Cramér's V 就是用来衡量关联强度的效应量，取值 0 到 1，越接近 0 越没关系。
我算出来 0.051，所以基本可以认定没有关联。

**Q：为什么用 PR-AUC 而不是 ROC-AUC？**
因为正类只有 6.13%，是不平衡分类。ROC 曲线在负类占绝大多数时会过于乐观，
PR 曲线（精确率-召回率）能更真实地反映模型在识别少数类上的能力。

**Q：你说的「口径」是什么意思？**
就是统计范围的定义。比如「购买件数」这个指标，是包含那几个超大额订单，还是把它们剔掉，
得到的结果完全不一样（2.54 件 vs 1.85 件）。所以做数据分析必须先说清楚口径。

**Q：这个分析对业务有什么用？**
最直接的是三条：① 大促预算集中在 11 月，618 不投；② 尿裤做囤货型促销、奶粉做订阅制锁复购；
③ 囤货预测模型可以提前识别大单，用于库存预占和包材准备。
